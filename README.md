# MERN Todo App

A full-stack Todo Application built using React, Node.js, Express.js, MongoDB, and JWT Authentication.

## Features

- User Registration
- User Login
- JWT Authentication
- Create Todo
- View Todos
- Update Todo Status
- Mark Complete / Undo
- Delete Todo
- Logout Functionality

## Tech Stack

### Frontend
- React
- React Router DOM
- Axios

### Backend
- Node.js
- Express.js
- JWT
- Mongoose

### Database
- MongoDB

## Installation

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## Environment Variables

Create a `.env` file inside backend folder:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```
